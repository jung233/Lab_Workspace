# BCA Standard Curve — declarative demonstration pack

Generated by composing existing `PrimitiveRegistry` operations; **contains no Python source code**. The content remains a **draft** and is not a verified BCA assay for research measurements without an approved SOP and user's review.

Inputs: raw standard concentrations/absorbances, blank absorbance, sample absorbance and dilution factor.

Operations: blank adjustment -> linear fit -> sample inverse -> range warning -> dilution adjustment -> unit conversion -> auditable trace.

To install a derived production pack, validate schemas, supported primitives, unit compatibility, run golden fixtures, approve and freeze content hashes. A template or calculation pack imported by AI is not automatically approved.
