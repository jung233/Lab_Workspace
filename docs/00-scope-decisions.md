# 00｜产品定位、范围与冻结决策

**文档名称：Lab Workspace — Product & Engineering Baseline V2.0**  
**状态：待工程评审的可实施设计，不是已开发完成的软件**  
**基线日期：2026-10-15**  
**目标系统：Windows Desktop + Android APP + iOS APP**

## 0.1 产品定义

Lab Workspace 是一个**单用户、本地优先、面向生物医学实验的可执行研究工作台**。将实验项目、样本及处理条件、Protocol、逐步执行、时间与通知、BCA/WB/IF 等计算、AI 图片工具编排、原始文件、计算透明性与可选云同步归档连接为可追溯数据链。

目标是尽可能满足“任何生物实验都能即时记录；AI 用自然语言把新的 SOP 和计算步骤配置为可执行工作流；不必每种实验重构源代码”。

## 0.2 一票否决的系统边界

| 主题 | V2.0 决定 | 不做/限制 |
|---|---|---|
| 平台 | Windows、Android、iOS 原生安装包 | 不开发 Web / PWA 作为正式端 |
| 用户 | 单用户、多设备，每设备一个本地 Vault | 不提供账户注册、团队权限、共享实验室后台 |
| 可用性 | 无网络可记录、计时、读取本地数据、运行可信内置计算 | 多模态云 AI、云备份、To Do 在无网络时排队 |
| 数据主存 | SQLite + 本地 CAS（内容寻址仓库） | 云不作为在线主数据库 |
| Python | Windows 自带；Android/iOS 嵌入可信 Python；Windows 可用 Conda/venv | 不承诺手机任意 pip 原生库运行 |
| AI | OpenAI Python SDK 为优先适配器；Responses / Chat Completions；用户可选兼容供应商 | 没有内置浏览器端或中心 AI 中转服务 |
| 图片 | 交由多模态 AI 分析、生成计划并调用用户批准的图片工具 | 本地不打包 CV 模型做自动检测/分割；生成式图像不得用于科学定量 |
| 计算 | 每个派生数值都必须具备“展示原始计算” | 不可用模型自然语言当作逐步精确计算 |
| 原始数据 | 导入时 SHA-256；内容不可就地改写；Explorer 可有审计地删除 | 删除必须考虑引用、软删和备份 |
| 完整性 | 默认阈值 2 GiB，可配置；小文件每次逻辑打开读/写后核验，大文件导入时计算哈希但不每次全文复验 | 大文件快速检查并不能证明字节完全未修改 |
| 云端加密 | 可选；对 OneDrive/S3 目标、数据类别分别配置；可选择完全不加密 | 远端明文需明确隐私告知；加密丢失密钥无法恢复 |
| 扩展 | Protocol Pack + Calculation Pack + Skill Registry + Schema 检验 | 声明式工作流无需改源码；新原语/原生依赖仍需扩展软件 |

## 0.3 典型端到端流程

**BCA → WB**：新建实验、分组、样本处理 → 导入/AI 生成 Protocol Pack → 按时间执行 → 导入 BCA 仪器 CSV 或用 AI 从报告照片提取字段并人工确认 → Calculation Pack 计算标准曲线/浓度并显示完整运算 → WB 上样体积自动引用已确认结果 → 拍摄/导入 WB 原件 → AI 建议 ROI 与图片工具调用、用户确认 → 原像素确定性 ROI 统计与计算追踪 → 项目归档、文件 Explorer 可查 → 选择性同步/独立备份。

**未知实验**：无需 Protocol 直接“快速实验” → 随时添加 Action/Wait/Measurement/Image/Record 节点 → 记录原始数据 → 后续 AI 将历史操作反向整理成新的 Protocol 草稿。

## 0.4 功能优先级

- **P0 / 首个可用版**：本地 Vault、项目/Run、DAG、基本记录、计时提醒、样本/组别、通用计算引擎、BCA 示例 Pack、原始计算、文件 Explorer、导入 SHA、可恢复备份、基础模型接口。
- **P1**：AI 完整 Protocol/Tool Pack 自然语言生成、WB ROI AI 工具、OneDrive/S3 选择性同步、可选远端加密、To Do 同步、移动端全功能计算。
- **P2**：更高级的显微图像工具、完整双向 To Do、丰富社区 Pack、复杂插件扩展、跨设备增量缓存智能策略。

优先级是实施顺序，不意味着用户请求的功能将被永久取消。交付版本必须依据测试结果重新评审。

## 0.5 非目标与科学责任

平台不能自动保证方案的科研正确性、设备可靠性或监管合规；是否采用特定 BCA 拟合模型、WB 背景扣除方法、荧光实验采集参数，应由研究者审查及验证。临床、患者与未公开科研数据对第三方模型的外发需单独授权和遵守机构政策。
